# Change Request: CR-2025-08-09-01 — FinWiz Output Quality, Consistency, and Risk Normalization

Date: 2025-08-09 09:06 CEST
Author: Cascade (Senior Trusted Financial Advisor)
Status: Proposed
Scope: Improve output quality, consistency, and investor suitability across crews and final reporting; tighten config hygiene; add guardrails; enhance testing and performance.

## Objectives

- Elevate report credibility and usability for a 50-year-old investor with 1,000 CHF/month budget.
- Ensure strict adherence to project rules: final reporter has no tools; HTML-first formatting; evidenced, reproducible outputs.
- Reduce tech debt in YAML agents/tasks and unify cross-crew data contracts to simplify the final report assembly.

---

# Recommended Actions

- **[Contract: Standardize cross-crew output keys]**
  Define and enforce a stable context contract used by the reporter:
  - Stock crew `technical_detail_task` to output `ten_k_insights[]` with fields: `ticker`, `filing_url`, `filed_at`, `section`, `excerpt`, `sec_citation`. See `src/finwiz/crews/stock_crew/config/tasks.yaml` lines 62–71.
  - Stock crew screening/risk tasks to output `market_sentiment` per ticker with: `mean_score`, `counts`, `top_pos[]`, `top_neg[]` where each item has `headline`, `url`, `date`. See lines 36–49 and 87–95.
  - ETF crew to add optional `factsheet_highlights` and `top_holdings` arrays (ticker, weight, source_url, as_of) in `src/finwiz/crews/etf_crew/config/tasks.yaml` (extend `etf_technical_detail_task`).
  - Crypto crew to add `risk_score_standardized` and `thesis_bullets[]` for parity; `src/finwiz/crews/crypto_crew/config/tasks.yaml`.

- **[Reporter: Consume context only, no tools]**  
  Align prompts to the rule (no external calls at final step). In `src/finwiz/crews/report_crew/config/agents.yaml`:
  - Replace wording that implies querying a knowledge base or using tools (lines 145–157) with “consume upstream context from prior tasks and crews.”
  - Confirm the crew wiring sets an empty tool list for `investment_reporter`. Add a unit test to enforce this.

- **[Content quality: Remove off-topic phrasing]**  
  Clean residual crypto/engineering phrases:
  - `src/finwiz/crews/etf_crew/config/agents.yaml` lines 7–11 and `src/finwiz/crews/report_crew/config/agents.yaml` lines 7–11 mention “evaluate code quality, scalability solutions, consensus mechanisms.” Remove as non-financial.
  - Ensure all agent goals/backstories focus on financial analysis and family planning.

- **[Budget suitability hints upstream]**  
  While the reporter applies the 1,000 CHF/month constraint (`src/finwiz/crews/report_crew/config/tasks.yaml` task 2), add lightweight upstream hints:
  - Stock/ETF screening tasks: add “flag as suitable for DCA with 1,000 CHF/month budget” boolean and estimated min position size to ease portfolio construction.

- **[Risk scoring normalization]**  
  Unify risk scoring scale (0–5 or Low/Med/High with numeric mapping) across Stock, ETF, Crypto tasks:
  - Add `risk_score_standardized` and `risk_factors[]` to `stock_risk_assessment_task` and `etf_risk_assessment_task`.
  - Map crypto `risk_assessment_task` to the same scale.  
  This enables consistent portfolio risk aggregation in the final report.

- **[SEC coverage: Extend beyond 10-K]**  
  Optionally extend Stock crew to support `10-Q` for recency and `8-K` for material events:
  - New optional step flags: `include_10q: true`, `include_8k: true` (default false) with the same `excerpts[]` schema.
  - Ensure `sec_tool` is wired; TODO notes indicate refactor complete. Verify integration in stock crew toolset.

- **[ETF factsheets and holdings]**  
  Add factsheet parsing to `etf_technical_detail_task`:
  - Extract `expense_ratio`, `tracking_diff`, `replication_method`, `issuer`, `as_of`; parse `top_10_holdings` where available with citations.
  - Output `factsheet_url` and `as_of` for provenance.

- **[Dates and tokens: Unify formatters]**  
  You use `{full_date}`, `{current_year}`, `{timestamp}` across YAML. Add a single context provider to avoid divergence:
  - Standardize `full_date` = “YYYY-MM-DD”, `timestamp` = ISO8601, and ensure all crews use the same injection.

- **[HTML-first final checks]**  
  - Keep specialized crew outputs in Markdown as-is, but add a reporter-side validation step: HTML must conform to `docs/output_formatting_guide.md`.
  - Add an HTML snapshot test and basic validation (closing tags, UTF-8, title, publication date, sections “Synthèse 10-K” and “Sentiment du Marché” per `src/finwiz/crews/report_crew/config/tasks.yaml` lines 87–118).

- **[Async performance policy]**  
  Add an explicit annotation policy: all tasks may run async except the final in each sequential crew (docs already warn). Ensure code-level crew definitions set `async_execution=True` where I/O-bound and keep the final reporter synchronous.

- **[Caching and cost control]**  
  Implement a short-lived cache for repeated news/search queries within a run (e.g., 30–60 min TTL) to cut cost and latency. Cache keys: ticker + date bucket + tool name + query.

- **[Testing/QA additions]**  
  - Reporter conformance: `tests/test_reporter_output_format.py` asserts sections, emojis, and that final agent has zero tools.
  - Contract tests: `tests/test_yaml_contracts.py` to assert context keys presence (`ten_k_insights`, `market_sentiment`, etc.) from mock task results.
  - SEC tool: Ensure tests cover `10-K` citations, URL, filed date, and section mapping; extend for optional `10-Q`/`8-K`.
  - Maintain current default of skipping integration tests (`pyproject.toml` lines 97–102). Run full with `uv run pytest -m integration`.

- **[Config hygiene and examples]**  
  - Provide `.env.example` matching `.env` usage in README.
  - Add small sample outputs under `output/` as fixtures for tests (dated folder structure `output/{crew}/YYYY-MM-DD/` to declutter).

# Risks & Mitigations

- **[Schema drift]** Reporter may break if upstream keys change.  
  Mitigation: add contract tests; version the schema keys in docs.

- **[Tool cost/latency]** More upstream extraction increases calls.  
  Mitigation: short-lived caching; concurrent I/O with async.

- **[Over-localization mismatch]** Upstream English vs final French.  
  Mitigation: reporter performs synthesis/translation only; keep citations as-is.
