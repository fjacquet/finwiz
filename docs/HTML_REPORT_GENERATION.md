# HTML Report Generation from JSON Output

## Overview

FinWiz generates both machine-readable JSON files and human-readable HTML reports for all analysis results. This document explains how the HTML generation works and how to use it.

## Architecture

### Data Flow

```
FinWiz Analysis
    ↓
JSON Output Files (machine-readable)
    ↓
JSON to HTML Converter (Jinja2 templates)
    ↓
HTML Reports (human-readable)
```

### Components

1. **JSON Output Files**: Generated by FinWiz crews and flows
   - Location: `output/` directory
   - Format: Structured JSON with Pydantic validation
   - Purpose: Machine-readable, API-friendly, archival

2. **Jinja2 Templates**: Professional HTML templates
   - Location: `src/finwiz/templates/`
   - Format: Jinja2 template syntax
   - Purpose: Consistent, maintainable HTML generation

3. **JSON to HTML Converter**: Python utility
   - Location: `src/finwiz/utils/json_to_html_converter.py`
   - Purpose: Automated conversion of JSON to HTML

## Usage

### Convert All JSON Files to HTML

```bash
# Using make command (recommended)
make html-convert

# Or directly with Python
uv run python scripts/generate_html_reports.py
```

This will:
- Scan the `output/` directory for all JSON files
- Match each JSON file to its appropriate template
- Generate HTML files alongside the JSON files
- Report success/failure statistics

### Convert Specific File

```python
from finwiz.utils.json_to_html_converter import JsonToHtmlConverter

converter = JsonToHtmlConverter()
html_path = converter.convert_file(Path("output/portfolio/portfolio_review.json"))
print(f"Generated: {html_path}")
```

### Programmatic Usage

```python
from finwiz.utils.json_to_html_converter import convert_all_json_to_html

results = convert_all_json_to_html(output_dir="output")
print(f"Success: {len(results['success'])} files")
print(f"Failed: {len(results['failed'])} files")
```

## Template Structure

### Base Template

All templates extend `base_template.html` which provides:
- Responsive CSS framework
- Light/dark mode support
- Professional styling
- Consistent header/footer
- Mobile-friendly layout

### Template Blocks

```jinja2
{% extends "base_template.html" %}

{% block content %}
<!-- Your custom content here -->
<div class="section">
    <h2>{{ title }}</h2>
    <p>{{ description }}</p>
</div>
{% endblock %}
```

### Common Template Variables

All templates receive:
- `generation_date`: String timestamp of generation
- `timestamp`: Datetime object for formatting
- `source_file`: Path to source JSON file

Plus file-specific data from the JSON content.

## Troubleshooting

### No HTML Generated

**Problem**: JSON file exists but no HTML generated

**Solutions**:
1. Check if template exists for that file type
2. Verify JSON is valid (not malformed)
3. Check logs for specific error messages
4. Run converter with `--verbose` flag

### Template Not Found

**Problem**: "Template not found" error

**Solutions**:
1. Verify template exists in `src/finwiz/templates/`
2. Check template mapping in `JsonToHtmlConverter.TEMPLATE_MAPPING`
3. Add custom mapping if needed

### Rendering Errors

**Problem**: Template renders but with errors

**Solutions**:
1. Check JSON structure matches template expectations
2. Verify all required fields are present
3. Add default values in `_prepare_context()` method
4. Update template to handle missing fields gracefully

## Customization

### Adding New Templates

1. Create template in `src/finwiz/templates/`:
   ```jinja2
   {% extends "base_template.html" %}
   
   {% block content %}
   <!-- Your content -->
   {% endblock %}
   ```

2. Add mapping in `JsonToHtmlConverter`:
   ```python
   TEMPLATE_MAPPING = {
       "my_report.json": "my_template.html",
       # ...
   }
   ```

3. Test conversion:
   ```bash
   uv run python scripts/generate_html_reports.py
   ```

### Customizing Styles

Edit `src/finwiz/templates/base_template.html`:
- Modify CSS in `<style>` block
- Update color scheme
- Adjust responsive breakpoints
- Add custom fonts

### Adding Template Variables

Update `_prepare_context()` in `JsonToHtmlConverter`:

```python
def _prepare_context(self, data: dict[str, Any], json_path: Path) -> dict[str, Any]:
    context = data.copy()
    
    # Add custom variables
    context["custom_field"] = self._calculate_custom_value(data)
    
    return context
```

## Performance

### Benchmarks

- **Single file**: < 100ms
- **Portfolio (69 holdings)**: ~5 seconds
- **Full output directory**: ~10-15 seconds

### Optimization Tips

1. **Batch Processing**: Convert all files at once
2. **Template Caching**: Jinja2 automatically caches templates
3. **Parallel Processing**: Can be parallelized for large batches
4. **Incremental Updates**: Only convert changed files

## Best Practices

### For Template Development

1. **Extend base template**: Always use `{% extends "base_template.html" %}`
2. **Handle missing data**: Use Jinja2 defaults: `{{ field|default('N/A') }}`
3. **Test with real data**: Use actual JSON files for testing
4. **Mobile-first**: Design for mobile, enhance for desktop
5. **Accessibility**: Use semantic HTML and ARIA labels

### For Integration

1. **Generate after analysis**: Run converter after FinWiz completes
2. **Check for errors**: Monitor conversion results
3. **Archive both formats**: Keep JSON and HTML together
4. **Version templates**: Track template changes in git
5. **Document custom templates**: Add comments and documentation
