# FinWiz Documentation

Welcome to FinWiz, an AI-powered financial analysis platform that uses autonomous CrewAI agents to analyze cryptocurrencies, stocks, and ETFs with actionable investment recommendations.

## Quick Start

Get up and running with FinWiz in minutes:

1. **[Getting Started](getting-started.md)** - Installation and basic setup

## Key Features

### 🤖 AI-Powered Analysis
- Autonomous CrewAI agents for financial analysis
- Multi-asset support (stocks, ETFs, crypto)
- Real-time data integration

### 📊 Professional Reports
- HTML report generation with templates
- Portfolio analysis and recommendations
- Risk assessment and grading system

### 🔧 Developer-Friendly
- Python-first architecture
- Comprehensive testing framework
- Modular, extensible design
