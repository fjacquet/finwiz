# Tutorials

Welcome to the FinWiz tutorials! These learning-oriented guides will help you get started with FinWiz and master its core features through hands-on practice.

[TOC]

## Getting Started

Start here if you're new to FinWiz:

- **[Getting Started](getting_started.md)** - Install FinWiz and run your first analysis
- **[First Analysis](first_analysis.md)** - Complete walkthrough of analyzing a stock
- **[Portfolio Analysis](portfolio_analysis.md)** - Learn to analyze your investment portfolio

## What You'll Learn

Through these tutorials, you'll learn to:

- Set up FinWiz in your development environment
- Configure API keys and data sources
- Run comprehensive financial analysis on stocks, ETFs, and cryptocurrencies
- Interpret FinWiz's AI-generated insights and recommendations
- Analyze complete investment portfolios
- Generate professional financial reports

## Prerequisites

Before starting these tutorials, you should have:

- Basic knowledge of Python programming
- Understanding of fundamental investment concepts
- Access to required API keys (instructions provided in tutorials)

## Tutorial Structure

Each tutorial follows a consistent structure:

1. **Learning Objectives** - What you'll accomplish
2. **Prerequisites** - What you need before starting
3. **Step-by-Step Instructions** - Detailed walkthrough
4. **Expected Results** - What success looks like
5. **Next Steps** - Where to go from here
