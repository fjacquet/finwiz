# Output Formatting Standards for FinWiz

Standards for all reports generated by FinWiz agents.

## General Principles

Primary output is a comprehensive HTML report that is:

- Well-structured and easy to read
- Contains all necessary information for decision-making
- Professional and consistent

## Critical Rules

**DO NOT**:

- Return raw API responses as task result
- Include placeholder text like 'TODO'
- Include debugging information

**ALWAYS**:

- Ensure output is single, complete, well-formed HTML document
- Use UTF-8 encoding for emoji support
- Validate HTML structure before returning

## HTML Structure

### Required Elements

```html
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Report Title</title>
    <style>
        /* Professional CSS styling */
    </style>
</head>
<body>
    <h1>📊 Report Title</h1>
    <p><strong>Date:</strong> 2025-03-10</p>
    <!-- Content sections -->
</body>
</html>
```

### Content Structure

- Use proper heading hierarchy (h1-h6)
- Use semantic elements (sections, tables, lists)
- Include clear title and publication date
- Use tables for comparative data
- Use lists for sequential information
- Use emphasis (bold/italic) for important points

### Prohibited Elements

- No raw JSON data
- No API responses
- No debugging information
- No placeholder text or TODOs
- No unclosed or malformed HTML tags

## French Language Standards

### Required French Output

- All user-facing content in French
- Professional financial terminology
- Clear, actionable recommendations
- Proper accents and special characters

### Common Terms

- **Recommandation**: Recommendation
- **Acheter**: Buy
- **Conserver**: Hold/Keep
- **Vendre**: Sell
- **Risque**: Risk
- **Rendement**: Return
- **Portefeuille**: Portfolio
- **Analyse**: Analysis
- **Opportunité**: Opportunity
- **Amélioration**: Improvement

## Report Sections

### Standard Structure

1. **Executive Summary** (Résumé Exécutif)
   - Key findings
   - Main recommendations
   - Risk highlights

2. **Detailed Analysis** (Analyse Détaillée)
   - Fundamental analysis
   - Technical analysis
   - Risk assessment

3. **Recommendations** (Recommandations)
   - Specific actions
   - Price targets
   - Timeline

4. **Data Sources** (Sources de Données)
   - Citations with URLs
   - As-of dates
   - Confidence levels

## Final Reporter Pattern

### Configuration

```python
@final_reporter
@agent
def investment_reporter(self) -> Agent:
    return Agent(
        config=self.agents_config['investment_reporter'],
        tools=[],  # MUST be empty
        verbose=True
    )
```

### Implementation

```python
# Consolidate findings from context
consolidated_findings = context.get("analysis", "")

# Structure final HTML report
final_report = f"""
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Rapport FinWiz</title>
</head>
<body>
    <h1>📊 Rapport d'Analyse FinWiz</h1>
    <p><strong>Date:</strong> {current_date}</p>
    
    <section>
        <h2>Résumé Exécutif</h2>
        {executive_summary}
    </section>
    
    <section>
        <h2>Analyse Détaillée</h2>
        {consolidated_findings}
    </section>
    
    <section>
        <h2>Recommandations</h2>
        {recommendations}
    </section>
</body>
</html>
"""

return final_report
```

## Quality Checklist

Before returning HTML output:

1. ✅ **Validate HTML**: Well-formed with correct structure
2. ✅ **UTF-8 Encoding**: Supports emojis and French characters
3. ✅ **Completeness**: All required sections present
4. ✅ **Accuracy**: All data verified (tickers, figures)
5. ✅ **French Language**: All user-facing text in French
6. ✅ **No Placeholders**: No TODO or debugging text
7. ✅ **Professional Formatting**: Clean, readable layout
8. ✅ **Emojis**: Used strategically, not excessively
9. ✅ **Citations**: All sources cited with dates
10. ✅ **Actionable**: Clear recommendations provided
