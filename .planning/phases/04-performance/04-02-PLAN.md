   ```python
   """Crew execution wrapper with timeout and circuit breaker protection."""
   import asyncio
   import os
   import time
   from concurrent.futures import ThreadPoolExecutor
   from typing import Any
   from finwiz.tools.logger import get_logger

   logger = get_logger(__name__)

   CREW_TIMEOUT = int(os.getenv("FINWIZ_HOLDING_TIMEOUT", "300"))
   FAILURE_THRESHOLD = 3
   RECOVERY_TIMEOUT = 60.0

   _executor = ThreadPoolExecutor(max_workers=4)
   _crew_failures: dict[str, int] = {}
   _crew_circuit_open: dict[str, float] = {}
   ```

2. Implement `execute_crew_with_timeout()` as an async function:
   - Parameters: `crew_name: str`, `crew_instance: Any`, `inputs: dict[str, Any]`, `timeout: int = CREW_TIMEOUT`
   - Returns: `Any` (the crew result)
   - Raises: `CircuitBreakerOpenError` if circuit is open, `TimeoutError` if timed out

   Logic:
   a. **Circuit breaker check**: If `crew_name` is in `_crew_circuit_open` and less than `RECOVERY_TIMEOUT` seconds have passed, raise `CircuitBreakerOpenError(f"Circuit breaker open for {crew_name}")`
   b. If recovery timeout has passed, delete the entry (half-open: allow retry)
   c. **Execute with timeout**: Use `asyncio.wait_for(loop.run_in_executor(_executor, crew_instance.kickoff, inputs), timeout=timeout)`
      - CRITICAL: crew.kickoff() is SYNCHRONOUS. It MUST be wrapped in run_in_executor() or it will block the event loop. The `inputs` dict must be passed as a keyword argument. Use a lambda: `lambda: crew_instance.kickoff(inputs=inputs)`
   d. **On success**: Reset `_crew_failures[crew_name] = 0`, return result
   e. **On failure** (TimeoutError or any Exception):
      - Increment `_crew_failures[crew_name]`
      - If failures >= FAILURE_THRESHOLD: set `_crew_circuit_open[crew_name] = time.time()` and log "Circuit breaker OPEN for {crew_name}"
      - Re-raise the exception

3. Define `CircuitBreakerOpenError(RuntimeError)` exception class in the same module.

4. Implement `reset_circuit_breakers()` function for testing:
   - Clears `_crew_failures` and `_crew_circuit_open`

   Tests:
   a. `test_execute_crew_with_timeout_success`: Mock crew.kickoff() to return immediately. Assert result is returned and _crew_failures is reset.
   b. `test_execute_crew_with_timeout_timeout`: Mock crew.kickoff() to sleep longer than timeout (use a small timeout like 0.1s and a mock that sleeps 1s). Assert TimeoutError is raised.
   c. `test_circuit_breaker_opens_after_threshold`: Call execute_crew_with_timeout 3 times with a failing crew. Assert 4th call raises CircuitBreakerOpenError.
   d. `test_circuit_breaker_half_open_after_recovery`: Open circuit, patch `time.time` to advance past RECOVERY_TIMEOUT, assert next call attempts execution.
   e. `test_reset_circuit_breakers`: Open circuit, call reset, assert next call succeeds.

   ```python
   def _run_crew_with_timeout(self, crew_name: str, crew_instance: Any, inputs: dict[str, Any]) -> Any:
       """Execute crew with timeout and circuit breaker protection."""
       import asyncio
       from finwiz.infrastructure.resilience.crew_execution import execute_crew_with_timeout
       try:
           loop = asyncio.get_running_loop()
       except RuntimeError:
           loop = None

       if loop and loop.is_running():
           # Already in async context -- create task (this shouldn't normally happen
           # since crew_factory methods are called from sync context)
           import concurrent.futures
           with concurrent.futures.ThreadPoolExecutor() as pool:
               future = pool.submit(
                   asyncio.run,
                   execute_crew_with_timeout(crew_name, crew_instance, inputs)
               )
               return future.result()
       else:
           return asyncio.run(
               execute_crew_with_timeout(crew_name, crew_instance, inputs)
           )
   ```
