<objective>
Refactor the rate limiter from sliding window + asyncio.sleep() cooldowns to a token bucket algorithm using aiolimiter, and replace blocking sleep calls in data collection with rate limiter acquire() calls.

Purpose: Eliminate sequential bottlenecks where API calls block on fixed cooldown sleeps, enabling true concurrent data fetching (PERF-01, PERF-02).
Output: Refactored rate_limiter.py with per-provider AsyncLimiter instances, updated callers, and unit tests.
</objective>
