  <action>
    Create `tests/unit/data/test_adapter_fallback_scenarios.py` containing a test class `TestAdapterFallbackScenarios`. This specifically tests failure and degradation scenarios NOT covered by the existing `test_data_source_orchestrator.py` (which covers happy paths and simple fallback).

    **CRITICAL RULES:**
    - Use `mocker` fixture exclusively. NEVER import from unittest.mock.
    - All tests are `async` with `@pytest.mark.asyncio` (DataSourceOrchestrator.get_fundamental_data is async).
    - Use `mocker.Mock(spec=...)` for adapter mocks and `mocker.AsyncMock` for async methods.
    - Import error classes from `finwiz.data.adapters.base_adapter`.

    **Fixtures (inside the test class):**
    ```python
    @pytest.fixture
    def orchestrator(self):
        return DataSourceOrchestrator(
            total_timeout=10.0,
            per_source_timeout=3.0,
            enable_validation=True,
        )
    ```

    **Test 1: `test_all_adapters_unavailable_falls_to_industry_averages`**
    - Mock ALL adapters in `orchestrator.adapters` with `is_available()` returning `False`.
    - Call `await orchestrator.get_fundamental_data("AAPL", sector="Technology")`.
    - Assert `result.used_fallback is True`.
    - Assert `"IndustryAverages" in result.sources_succeeded`.
    - Assert `result.is_complete()` (IndustryAverages provides all 4 fields).
    - Assert `result.confidence < 0.6` (low confidence for fallback-only data).

    **Test 2: `test_primary_adapter_raises_data_acquisition_error`**
    - Create 2 mock adapters. First raises `DataAcquisitionError("Connection refused")` from `get_fundamental_data`. Second returns complete `FundamentalData`.
    - Replace `orchestrator.adapters` with `[mock_adapter_1, mock_adapter_2]`.
    - Call `await orchestrator.get_fundamental_data("AAPL")`.
    - Assert first adapter's source_name is in `result.sources_failed`.
    - Assert second adapter's source_name is in `result.sources_succeeded`.
    - Assert `result.is_complete()`.
    - Assert any warning contains "Connection refused".

    **Test 3: `test_primary_adapter_raises_timeout_error`**
    - Same as Test 2 but first adapter raises `TimeoutError("3s timeout exceeded")`.
    - Assert first adapter in `sources_failed`.
    - Assert any warning contains "Timeout" or "timeout".

    **Test 4: `test_primary_adapter_returns_invalid_data_rejected`**
    - First adapter returns `FundamentalData` with `return_on_equity=5.0` (invalid: >2.0 threshold in `is_valid()`).
    - Second adapter returns valid complete data.
    - Assert first adapter's source_name is in `result.sources_failed`.
    - Assert result uses data from second adapter.
    - Assert any warning contains "failed validation".

    **Test 5: `test_all_adapters_fail_and_fallback_fails`**
    - Mock ALL adapters with `is_available()=False`.
    - Mock `orchestrator.fallback_adapter.get_fundamental_data` as `mocker.AsyncMock(side_effect=Exception("IndustryAverages DB corrupted"))`.
    - Call `await orchestrator.get_fundamental_data("AAPL", sector="Technology")`.
    - Assert result does NOT raise an exception (graceful degradation).
    - Assert `result.is_complete() is False` (no data available).
    - Assert any warning contains "Fallback failed".
    - Assert `result.get_completeness_score() == 0.0`.

    **Test 6: `test_partial_data_degradation_with_lineage_tracking`**
    - Create mock adapter that returns `FundamentalData` with ONLY `return_on_equity=0.25` and `debt_to_equity=0.5` (revenue_growth and profit_margin are None).
    - Set it as the only adapter with `is_available()=True`.
    - Call `await orchestrator.get_fundamental_data("AAPL", sector="Technology")`.
    - Assert `result.return_on_equity == 0.25` (from mock adapter).
    - Assert `result.debt_to_equity == 0.5` (from mock adapter).
    - Assert `result.revenue_growth is not None` (filled by IndustryAverages).
    - Assert `result.profit_margin is not None` (filled by IndustryAverages).
    - Assert `result.lineage.return_on_equity_source == mock_adapter.source_name`.
    - Assert `result.lineage.revenue_growth_source == "IndustryAverages"`.
    - Assert `result.used_fallback is True`.

    **Test 7: `test_total_timeout_exceeded_graceful_degradation`**
    - Create orchestrator with `total_timeout=0.01` (10ms -- will timeout immediately).
    - Create mock adapter with `is_available()=True`.
    - Mock `get_fundamental_data` as `mocker.AsyncMock` that does `await asyncio.sleep(1.0)` (takes 1 second, far exceeding 10ms timeout).
    - Call `await orchestrator.get_fundamental_data("AAPL", sector="Technology")`.
    - Assert any warning contains "timeout" (case-insensitive).
    - Assert result still has data (from fallback after timeout).

    **Test 8: `test_first_source_complete_stops_waterfall`**
    - Create 2 mock adapters. First returns complete data (all 4 fields). Second should NOT be called.
    - Replace `orchestrator.adapters` with `[mock_adapter_1, mock_adapter_2]`.
    - Call `await orchestrator.get_fundamental_data("AAPL")`.
    - Assert `mock_adapter_2.get_fundamental_data.call_count == 0` (waterfall stopped).
    - Assert `result.is_complete()`.
    - Assert `result.used_fallback is False`.

    Keep the file under 300 lines. Use `datetime.now()` for FundamentalData timestamps.

  <action>
    Create `tests/unit/reporting/test_html_output_validation.py` containing a test class `TestHtmlOutputValidation`. Uses BeautifulSoup (already in project deps) to parse and validate generated HTML.

    **CRITICAL RULES:**
    - Use `mocker` fixture exclusively. NEVER import from unittest.mock.
    - Parse HTML with `BeautifulSoup(html, "html.parser")` (stdlib parser, no lxml needed).
    - Use the `_create_sample_enriched_analysis()` method from `EnrichedAnalysisReportGenerator` as the basis for test data. Modify it for specific tests.
    - The template is at `src/finwiz/templates/enriched_analysis_report.html` and auto-discovered by the generator.

    **Imports:**
    ```python
    import pytest
    from bs4 import BeautifulSoup
    from finwiz.reporting.enriched_analysis_report_generator import EnrichedAnalysisReportGenerator
    ```

    **Fixtures (inside the test class):**
    ```python
    @pytest.fixture
    def generator(self):
        return EnrichedAnalysisReportGenerator()

    @pytest.fixture
    def sample_data(self, generator):
        return generator._create_sample_enriched_analysis()

    @pytest.fixture
    def sample_html(self, generator, sample_data):
        return generator.generate_report(sample_data)
    ```

    **Test 1: `test_html_has_doctype_and_root_elements`**
    - Generate HTML from sample data.
    - Assert HTML string starts with `<!DOCTYPE html>` (case-insensitive check: `html.lower().startswith("<!doctype html>")`).
    - Parse with BeautifulSoup. Assert `soup.find("html")` exists.
    - Assert `soup.find("head")` exists.
    - Assert `soup.find("body")` exists.

    **Test 2: `test_html_has_utf8_charset`**
    - Parse generated HTML.
    - Find `<meta charset="...">` tag: `soup.find("meta", attrs={"charset": True})`.
    - Assert charset value is "UTF-8" (case-insensitive).
    - Alternatively check for `<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">`.

    **Test 3: `test_html_has_style_block`**
    - Parse generated HTML.
    - Assert `soup.find("style")` exists (CSS is inline in the template).
    - Assert the style block contains at least some expected CSS class (e.g., `"primary-color"` or `"card-background"`).

    **Test 4: `test_html_xss_prevention_script_tag_escaped`**
    - Create sample data and set `sample_data["ticker"] = '<script>alert("xss")</script>'`.
    - Generate HTML.
    - Assert the raw string `<script>alert` does NOT appear in the HTML output.
    - Assert the escaped version appears: check that `&lt;script&gt;` or the HTML entity equivalent is present.
    - Parse with BeautifulSoup. Assert `soup.find("script")` is None or does not contain "alert" (no executable script injected).

    **Test 5: `test_html_xss_prevention_event_handler_escaped`**
    - Set `sample_data["company_name"] = 'Evil Corp" onmouseover="alert(1)'`.
    - Generate HTML.
    - Assert `onmouseover` does NOT appear as an HTML attribute in the output.
    - Parse with BeautifulSoup. Check no tags have an `onmouseover` attribute: `assert not soup.find(attrs={"onmouseover": True})`.

    **Test 6: `test_html_contains_key_content_sections`**
    - Generate HTML from default sample data.
    - Parse with BeautifulSoup. Get all text: `text = soup.get_text()`.
    - Assert the following strings appear in the text (they come from template sections):
      - The ticker name ("TEST").
      - The grade ("A").
      - The recommendation ("BUY").
      - "Executive Summary" or equivalent section header.

    **Test 7: `test_jinja2_autoescape_enabled`**
    - Access the generator's Jinja2 environment: `generator.env`.
    - Assert `generator.env.autoescape is True`.
    - This is a direct configuration test, not an output test. It verifies the security setting is configured correctly at the source.

    **Test 8: `test_html_is_parseable_without_errors`**
    - Generate HTML from sample data.
    - Parse with `BeautifulSoup(html, "html.parser")`.
    - Assert the soup object is not None.
    - Assert `len(soup.find_all())` > 10 (page has substantial structure, not just a fragment).
    - Assert no `<![CDATA[` or broken tag artifacts in the raw HTML.

    **Test 9: `test_html_special_characters_in_rationale`**
    - Set `sample_data["investment_rationale"]` to a long string (500+ words, meeting the quality threshold) containing special characters: `"Revenue grew 25% YoY. P/E ratio < 30. Risk: 'moderate'. Debt/Equity & leverage acceptable."` repeated to reach word count.
    - Generate HTML.
    - Assert the `&` appears as `&amp;` or the raw text is properly escaped.
    - Assert `<` appears as `&lt;` when not part of an HTML tag.
    - Parse with BeautifulSoup to confirm no parsing errors.

    Keep the file under 300 lines. The generator uses a real Jinja2 template from `src/finwiz/templates/` so no mocking of the template is needed.
